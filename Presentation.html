Bonus Mechanics: Lucky Respin & Free Spins Frenzy

Two distinct bonus systems engineered to build tension and reward near-miss combinations

⚡ Lucky Respin (Near-Miss Hold & Spin)

  • Trigger Condition: When any 2 reels land on matching symbols while the 3rd reel misses (when the Lucky Respin rule is enabled).
  • Golden Reel Lock: The 2 matching reels lock in place with a 4px golden border highlight (#f59e0b).
  • Isolated 3rd-Reel Respin: The machine automatically grants a free respin on the remaining non-matching reel for 1.45s.
  • Heartbeat Suspense Audio: Plays respin_suspense.wav during the single-reel spin before evaluating the final 3-reel combination.
  • Single-Cycle Guard: Prevents infinite respin loops by disabling re-triggers on the respin evaluation pass.

🔔 Free Spins Frenzy (3x Bells Bonus)

  • Trigger Condition: Landing BELL-BELL-BELL on the center payline awards 25x Bet plus +5 Free Spins.
  • 2X Payout Multiplier: All winning combinations hit during Free Spins mode receive an automatic 2x multiplier boost.
  • Zero Bankroll Deduction: Free spins decrement remainingFreeSpins rather than deducting coins from the player's balance.
  • Triggering Wager Freeze: Bet modification controls are locked during Free Spins to preserve fairness on the triggering wager.
  • Bonus Banner HUD: Displays a live status banner showing remaining Free Spins and the active 2X multiplier badge.

Cryptographic RNG & 96.5% RTP Probability Model

Unbiased CSPRNG rejection sampling and pre-spin outcome determination

Weighted Probability & RTP Derivation

  • 7 (SEVEN) — 10% Weight: $P(7,7,7) = 0.10^3 = 0.10\%$ (1 in 1,000 spins, 100x payout)
  • BAR — 20% Weight: $P(\text{BAR}^3) = 0.20^3 = 0.80\%$ (1 in 125 spins, 50x payout)
  • BELL — 30% Weight: $P(\text{BELL}^3) = 0.30^3 = 2.70\%$ (25x payout + 5 Free Spins @ 2x)
  • CHERRY — 40% Weight: $P(\text{CHERRY}^3) = 0.40^3 = 6.40\%$ (10x payout)
  • Pre-Spin Lock: Following regulated gaming standards, outcomes[0..2] are drawn before the reels start moving, making client-side stopper timing manipulation impossible.

Eliminating 32-Bit Modulo Bias (RNGService.cs)

public static int GetSecureInt(int minValue, int maxValue)
{
    long diff = (long)maxValue - minValue;
    byte[] uint32Buffer = new byte[4];

    while (true)
    {
        CryptoProvider.GetBytes(uint32Buffer);
        uint rand = BitConverter.ToUInt32(uint32Buffer, 0);

        // Reject values in the incomplete upper bucket
        long maxValid = (1L << 32) - ((1L << 32) % diff);
        if (rand < maxValid)
        {
            return (int)(minValue + (rand % diff));
        }
    }
}

6-Phase Continuous Drum Tape & Spring-Damped Physics

Infinite virtual strip map, 3D cylindrical foreshortening, and damped cosine overshoot

6-Phase Reel Kinematics

  • Phase 1 — Upward Stepper Kickback (75ms): Reels pull slightly upward (-0.13 * sin(π * t / 0.075)) before launching downward.
  • Phase 2 — Rapid Acceleration: Accelerates at 68 symbols/sec² up to 24.5 + index * 1.1 symbols/sec.
  • Phase 3 — High-Speed Blur: Multi-pass vertical motion blur stretches symbol height proportionally to drum velocity.
  • Phase 4 — 6-Symbol Deceleration Runway: Stamps target symbol at ceil(pos) + 6 and decelerates via cubic ease-out 1 - (1 - u)^2.5.
  • Phase 5 — Physical Overshoot (+20.5px): Drops past the payline, firing reel_stop.wav and a cabinet jolt impulse.
  • Phase 6 — Damped Cosine Spring Rebound: Springs back to exact center payline alignment.

Continuous 3D Lever Spring-Damper & Cabinet Jolt

Second-order differential equations (a = -k·x - c·v) driving physical rebound and 3D perspective rendering

Second-Order Spring-Damper ODE

// 1. Lever Spring-Return (stiffness k = 220, damping c = 16.5)
const stiffness = 220;
const damping = 16.5;
const accel = -stiffness * state.leverPos - damping * state.leverVel;
state.leverVel += accel * dt;
state.leverPos += state.leverVel * dt;
state.leverPos = Math.max(-0.08, Math.min(1.0, state.leverPos));

// 2. Coupled Physical Cabinet Micro-Jolt (k = 340, c = 24)
const jAccel = -340 * state.cabinetJoltY - 24 * state.cabinetJoltVel;
state.cabinetJoltVel += jAccel * dt;
state.cabinetJoltY += state.cabinetJoltVel * dt;

Real-Time 3D Perspective Shaft & Knob

  • 5-Phase State Machine: idle → dragging / auto_pull → bottom_hold (90ms mechanical dwell) → spring_return.
  • 3D Angular Foreshortening: Sweeps angle $\theta$ from $-72^\circ$ (upright) to $+58^\circ$ (pulled), foreshortening the chrome shaft length at horizontal midpoint to simulate 3D tilt toward the player.
  • Perspective Ball Knob Scaling: Enlarges the ball handle by $+14\%$ at $\theta = 0^\circ$ (closest to camera) with a 3-stop radial specular highlight.
  • Top Rebound Overshoot: Allowing leverPos to reach -0.08 produces an authentic mechanical bounce past the upper stop.

Audio Synthesis & Zero-Server WebGL Asset Pipeline

Bypassing local file:// CORS restrictions with in-memory Base64 AudioBuffers and WebAudio oscillators

1. Hybrid Base64 In-Memory Audio Decoder

  • The file:// CORS Problem: Browsers block fetch() and XMLHttpRequest for local audio files when opening index.html directly from disk.
  • In-Memory Base64 Solution: All 8 synthesized WAV files are embedded as Base64 strings in AUDIO_BASE64 and decoded directly in RAM into native WebAudio AudioBuffer instances via ctx.decodeAudioData().
  • Zero-Latency Procedural Oscillators: High-frequency tactile ticks (leverRatchet, leverLatch, leverSpring, reelTick) are synthesized in real time using WebAudio OscillatorNode waveforms.
  • Safe Autoplay Unlock: Automatically resumes suspended audio contexts on the first user click, touch, or keypress.
